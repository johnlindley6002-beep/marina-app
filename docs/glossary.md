# Glossary

One word for one thing, in everything a person reads: screens, dictionaries, emails, error messages and the dev panel. Code identifiers and storage keys keep their old names (`voyager`, `owner`, `u-owner`, `vesselUse` and so on); only the words on screen follow this list.

## Two cases the glossary does not change

- **The owner of a boat** is still the "owner". The pre-arrival form asks for the boat's owner, and the boat owner and the berth holder are often different people.
- **"Guest or passenger"** on a crew list is a person on board, not the visiting boater, so it keeps its meaning there.

## Where it applies

Dictionaries in all four languages (`lib/i18n/locales`), the email text (`lib/i18n/mail.ts`), the reletting copy (`data/site.ts`), the mock layer's messages and persona labels (`data/mock`), the staff, owner and dev screens, page titles and marina descriptions. Add new copy in these words.
